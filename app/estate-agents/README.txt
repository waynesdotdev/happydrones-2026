app/estate-agents/  -  FOR ESTATE AGENTS (/estate-agents/)
==========================================================

  page.js   hero, perks, how it works, the FPV route, agent pricing,
            questions and a final call to action

The discount, perks, steps and questions all come from AGENT_OFFER in
lib/site.js. Change "10%" or "minPerMonth" there and every mention
updates. Buttons link to /?role=agent#contact, which opens the form
with "Estate agent" already picked.
