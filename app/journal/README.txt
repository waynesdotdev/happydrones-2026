app/journal/  -  THE VIEWING ROOM (/journal/)
=============================================

You don't need to edit anything here to add posts.
Posts are Markdown files in content/posts/. See content/posts/README.txt.

  page.js          the list page: featured post, filters, search
  [slug]/page.js   the template used for EVERY post page

The filter buttons are made from your post categories automatically.
The featured post is whichever post has  featured: true  (newest wins).
A link like /journal/?cat=Guides opens with that filter on.
